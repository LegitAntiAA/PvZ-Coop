# Delivery decisions — 2026-11-13

- **Mystery discount:** quadratic basis points `(2100 + 475*x + 125*x*x + 1)/3`, `x=clamp(D,1,10)-1`, gives exact7/20/55% anchors and strictly increasing adjacent increments. Currency rounds upward. The old adaptive price floor remains unless it would erase the card's larger intrinsic discount.
- **Shared Zen Garden:** host applies ordered ordinary tool/mouse actions; clients receive bounded presentation records keyed by plant network ID plus shared garden/supply state. Never copy host potted-plant records into client personal saves. Tool targeting uses the coordinates of that action rather than the host's highlighted object. Native purchase/sale confirmation remains host-owned, with feedback for client sale attempts.
- **Cursor identity:** protocol34 describes semantic packet IDs or chooser `(owner,seed,imitater)` targets and relative offsets. Rendering resolves current geometry every frame; expired/missing identities hide rather than linger over another plant. Glove cursors use a plant network ID and guarded ghost lookup.
- **Tutorial lifetime:** menu-only modal, seven short Russian steps, actual control geometry, native idle zombie. Preview dialogs cannot perform actions; the lobby previews connection controls without disconnecting an active session. Close/Escape/scene transitions restore the layout and synchronously dispose the zombie before any board resets the global effect holder. Independent review found the initial deferred-delete lifetime defect; explicit pre-board cleanup resolves it.
- **Tutorial rendering:** SDL's legacy polygon path does not paint these shapes. The final speech body and tail share one cached ARGB coverage image with a single exterior border, four-by-four edge sampling and a soft shadow; no global renderer changes. Cache invalidation follows step/size changes. Trebuchet MS is loaded from the existing Windows Fonts directory, with native fallback and no redistributed font files. Fast reveal respects UTF-8 boundaries; local quiet sound instances obey user mute/volume and never broadcast typing to peers.
