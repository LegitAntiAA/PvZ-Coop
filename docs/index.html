Как начать играть

Проект собирается из исходников. Нужна собственная копия оригинальной игры.

Соберите игру

Visual Studio 2022+, C++20, конфигурация ReleaseGOTY. Скопируйте main.pak и properties/ из вашей копии PvZ в папку Plants Vs. Zombies/.

Подключите друзей

Создайте сеть в Radmin VPN (или используйте LAN). Хост нажимает HOST GAME, остальные вводят его IP и порт 27713.

Защищайте газон

Хост выбирает режим. Все игроки автоматически переходят в игру. Для PvP сначала выберите команды.
